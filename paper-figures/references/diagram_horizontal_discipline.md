# 学术图表【0 度水平文字与无遮挡遮罩】通用铁律

无论是在 IEEE/ACM 论文插图（单双栏排版），还是在学术会议大型海报/易拉宝中，**文字的可读性是科研可视化的第一生命线**。

---

## 一、为什么倾斜旋转文字是“反人类设计”？

在许多学术图表初稿中，绘图者常顺应箭头的倾斜角度（如 $30^\circ$、$45^\circ$、$60^\circ$）将文字进行同样角度的旋转（例如 `rotation=45`）：
- **论文阅读场景**：读者在阅读 PDF 或打印稿时，倾斜文字迫使其歪头或旋转阅读设备，极度破坏阅读心流；
- **展会海报场景**：参会同行站立于展架前（视距 1.5–3 米），倾斜或倒挂文字辨识度急剧下降，严重影响学术成果的传播效率。

**全管线铁律：无论连线如何倾斜弯折，文字必须 100% 保持 0 度绝对水平！**

---

## 二、四大通用绘图纪律

### 1. 【0 度水平标注】：斜向连线文字水平放置
- **原则**：沿斜向箭头的标注文字，严禁沿线倾斜。应将文字置于箭头的中点上方、下方或侧面；
- **实现示例 (matplotlib)**：
  ```python
  # 斜线端点为 (P_start, P_end)，取中点或偏侧计算位置
  pos_txt = (P_start + P_end) / 2.0 + np.array([0, 2.5])
  ax.text(pos_txt[0], pos_txt[1], "认知深化路径",
          fontsize=12.0, fontweight='bold', color='#1A202C',
          rotation=0,  # 强制 0 度水平！
          ha='center', va='center', zorder=5,
          bbox=dict(facecolor='white', edgecolor='none', pad=2.0))
  ```

### 2. 【文字无穿帮白色遮罩】：避免线条穿字
- **现象**：当多条数据流、关系虚线在画布中纵横交错时，线条直接横穿字迹，导致文字不可读；
- **规范**：任何悬浮在连线、箭头、网格之上的文字块，必须自带与背景同色的纯色遮罩（通常为纯白 `facecolor='white'` 或背景浅灰色）；
- **参数标准**：
  - matplotlib: `bbox=dict(facecolor='white', edgecolor='none', boxstyle='round,pad=0.25', alpha=1.0)`；
  - python-pptx: 使用 `create_horizontal_callout(...)`，自带纯白填充与 0.5pt 浅灰边框。

### 3. 【垂直长条容器】：汉字自然竖向堆叠流
- **场景**：流程闭环的左侧或右侧长条指示框（如“评估革新”、“内容联动”）；
- **错误做法**：将整个长方形或文字旋转 $90^\circ$ 或 $-90^\circ$；
- **正确做法**：容器竖置，但内部汉字采用换行字符流自然堆叠（即 `'内\n容\n联\n动'`），每个字本身依然保持直立端正，读者自上而下自然扫读。

### 4. 【字号与视距保底阶梯】：
- **IEEE/ACM 论文图（单栏 3.5 in / 双栏 7.16 in）**：
  - 核心标注 $\ge 8\text{ pt}$；
  - 次级图注/坐标轴刻度 $\ge 6.5\text{ pt}$；
  - 绝对禁止小于 $6\text{ pt}$（出版印刷硬红线）。
- **学术海报/易拉宝（60cm × 160cm 典型展板）**：
  - 1:1 物理印刷尺寸下，图内文字必须 $\ge 22\text{ pt}$；
  - 1:2 PPTX 编辑版下，图内文字必须 $\ge 11.0\text{ pt}$；
  - 绝对严禁因为缩放图框导致文字缩小至 $10\text{ pt}$ 以下。
